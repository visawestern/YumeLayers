# План тестового покрытия YumeLayers

Версия плана: 1.0
Методология: после каждого раунда проверка покрытия «адвокатом дьяволом» —
ищем пробелы, рискованные места и то, что тесты НЕ проверяют.

Легенда статусов:
- [ ] не покрыто
- [~] частично покрыто
- [x] покрыто
- [!] покрыто, но есть известные пробелы/риски
