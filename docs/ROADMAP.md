# YumeLayers — План-чеклист ВСЕХ работ до целевого результата

> Целевой результат: **локальный генератор аниме-видео**, который
> 1. обучается на собственных видео пользователя,
> 2. генерирует кадр по слоям (фон / объекты / солнце-свет) — ветки считаются
>    раздельно (параллельно на нескольких GPU, либо последовательно на одной),
>    затем **собираются** в итоговый кадр,
> 3. строит движение (монтаж/интерполяция/диффузия в латентном пространстве),
> 4. отдаёт результат в 480p и выше — резко, без «мыла»,
> 5. управляется через локальный UI и API.

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово/закрыто.
