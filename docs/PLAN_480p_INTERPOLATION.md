# План: реконструкция и видеосинтез из двух опорных кадров в 480p

## Текущее состояние
- Интерполяция работает через `/api/interpolate` и `interpolateVideo`
- Текущие кадры обучаются/интерполируются в 80×56 / 128×72 — результат мутный
- Пользователь требует 480p реконструкцию с проекцией движения из эталонного видео

## Цель
Построить сквозной пайплайн: два опорных кадра → обучение/дообучение VAE на 480p патчах → интерполяция латентов с проекцией движения, полученного из эталонного видео, → выход 854×480 mp4 с сохранением фона/объектов/света.

## Ограничения
- TDD обязательно, без заглушек
- Файлы ≤600 строк, функции ≤120 строк
- Линт `scripts/lint-codeguide.py` exit 0
- Коммит+пуш каждый раунд
- Python не в продуктовом коде
- API-интерфейс, без кликов UI
