# GPU-конвейеризация — план-чеклист раундов

Цель: полноценное обучение на Metal GPU (AMD Radeon Pro 5500M) с минимальным числом синхронизаций.

## Раунды

### Раунд 1. GPU-тензоры и ядро операций
- [ ] GPUTensor (MTLBuffer + форма)
- [ ] Шейдеры: matmul (с transA/transB), add, mul, tanh, tanh_grad, addBias, sumCols, adam_update
- [ ] GpuSession: один command buffer на шаг, пул буферов
- [ ] Тест корректности всех операций против CPU-эталона (max delta < 1e-4)
- [ ] Оценка адвоката ≥ 95%

### Раунд 2. Обучение MLP/автоэнкодера на GPU
- [ ] Forward+backward полностью на GPU (батч-векторизация)
- [ ] Adam на GPU
- [ ] Обучение VAE-АЕ на 32×32: loss совпадает с CPU-версией
- [ ] Оценка адвоката ≥ 95%

### Раунд 3. Диффузия на GPU + интеграция
- [ ] Diffusion MLP на GPU (forward + backprop)
- [ ] Генерация через GPU
- [ ] Полный пайплайн vae→diffusion→generate на Metal
- [ ] Оценка адвоката ≥ 95%

### Раунд 4. Производительность 64×64 и выше
- [ ] Бенчмарк: 64×64 за < 60 с на 10 эпох
- [ ] Сокращение числа синхронизаций до 1 на шаг
- [ ] Оценка адвоката ≥ 95%

## Критерии оценки (адвокат дьявола)
- Корректность vs CPU: 1e-4 → 100%
- Скорость: цель — не хуже CPU для средних размеров, радикально лучше на больших
- Отсутствие утечек памяти/буферов

Статус каждого пункта обновляется после каждого раунда.
